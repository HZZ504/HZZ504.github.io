### Level 3 — 定时任务

- **Claude Code Loops 上手 7 分钟**：Developers Digest "[Claude Code Loops in 7 Minutes](https://www.youtube.com/results?search_query=Claude+Code+Loops+in+7+Minutes+Developers+Digest)"（4.2万次观看）：Loop 限定在当前会话、带最高 10% 调度偏移；示例包括每日 git recap 和 Hacker News 邮件自动化，并讲清何时该改用更持久的方案。
- **Cowork 定时任务已是教程标配**：Tina Huang（38万次观看）与 AI Foundations（6.8万次观看）的 Cowork 教程都单列 "Scheduled Tasks" 章节——晨报、周报、项目内定时任务是最常见的三个落地场景。

### Level 4 — Connectors & MCP

- **Cowork 插上你已付费的工具**：Dr. Fernando De La Peña Llaca 的图文帖（👁33）演示小企业玩法：Cowork 桌面端 → Customize → Plugins 搜索 "Small Business" 安装 → 连上 QuickBooks / HubSpot / Canva / DocuSign / Google，一句 prompt 完成月度对账并生成给会计的摘要包。
- **MCP 选型看老片**：Edmund Yong "[800+ hours of Learning Claude Code in 8 minutes](https://www.youtube.com/results?search_query=800+hours+of+Learning+Claude+Code+in+8+minutes+Edmund+Yong)"（91万次观看）的 "My favorite MCP servers" 章节仍是被引用最多的 MCP 入门清单。
- **Turing × Anthropic 官方课程体系**：[@turingcom](https://x.com/turingcom)（💬1 ❤️3 👁73）宣布 Frontier Fellow 福利：3 个月 Claude Max 5x + Anthropic 主讲四部曲工作坊——Claude Code Foundations/Advanced + Claude Cowork Foundations/Advanced，官方培训首次把 Cowork 与 Code 并列成体系。

### Level 5 — Hooks 自动化控制

- **PostToolUse 自动格式化 + 拦截危险命令**：John Kim tips 47–50：Hooks 可拦截任意动作——PostToolUse 自动跑 prettier、PreToolUse 阻断危险命令，把"希望发生"变成"必然发生"。
- **让 Claude 自己写 Hook**：YouTube Shorts "[Claude sets up a PostToolUse hook for itself](https://www.youtube.com/results?search_query=Claude+sets+up+a+PostToolUse+hook)"（584次观看）演示元操作：直接让 Claude 为自己配置 Hook，配置成本趋近于零。

### Level 6 — 子代理编排

- **像 tech lead 一样管 sub-agents**：Sajjaad Khader "[Learn 80% of Claude Code in 10 Minutes](https://www.youtube.com/results?search_query=Learn+80%25+of+Claude+Code+in+10+Minutes+2026+Sajjaad+Khader)"（15万次观看）第 6 层：任务队列 + plan mode + ultra-thinking，工程师的角色正在变成 AI 团队管理者。
- **Subagents = 隔离上下文**：John Kim Tip 39/40：sub-agent 的核心价值是独立 context window，避免主会话被污染；同时警惕"指令过载"——每个 agent 只给它该知道的。

### Level 7 — 专家级工作流

- **六步 AI 原生设计流程（今日新片）**：Peter Yang "[Full Tutorial: From Idea to App with Claude Design and Claude Code in 25 Minutes](https://www.youtube.com/results?search_query=From+Idea+to+App+with+Claude+Design+and+Claude+Code+Peter+Yang)"（3,178次观看 · 11小时前）：定义用户问题 → design.md → Claude Design 原型 → 一份 HTML spec 打通产品/设计/技术 → 覆盖边缘 case → Claude Code 实现；核心论点：规划应占一半以上时间。
- **精读 Anthropic 官方"围堵 Claude"长文**：[@yibie](https://x.com/yibie)（👁123）强推 Anthropic 工程团队 7 月 29 日的长文（[How we contain Claude](https://www.anthropic.com/engineering/how-we-contain-claude)）：4 个真实安全事故 + 3 种隔离模式（claude.ai / Claude Code / Cowork），核心教训一句话——不要信任 agent 的自我约束，要信任架构隔离。
- **开源平替生态成型**：[@Justshareit518](https://x.com/Justshareit518)（👁23）介绍 [OpenWork](https://news.ycombinator.com/item?id=46612494)——开源版 Claude Cowork，基于 OpenCode，跨 macOS/Windows/Linux，可在 Cursor、Claude Code、Codex 间共享 workflows、MCPs 和 skills。

## 六、跨平台趋势总结

1. **安全叙事成为主线**：Anthropic 官方长文《How we contain Claude》引发 X 精读潮，叠加 7/23 披露的 SharedRoot 沙箱逃逸（已修复）与 Reddit 11GB 误删事故——"最小化挂载 + 备份 + 信任架构不信任模型"正在成为 Cowork 使用共识。
- 2. **官方培训体系化**：Turing × Anthropic 把 Cowork 与 Code 并列开设 Foundations/Advanced 四门课，Cowork 从"新玩具"升级为需要正式培训的生产力工具。
3. **开源平替生态加速**：OpenWork（Show HN）主打跨工具共享 skills/MCP/workflows，与 1 月 OpenCode OAuth 被封事件形成呼应——闭环生态与开放生态的张力持续。
4. **无代码自动化教程爆发**：X 与 YouTube 同步出现 "No-Code Automation"（Data Science in Action 图解）、小企业插件包等面向非工程师的内容，Cowork 的 "normie" 市场定位正在兑现。
5. **设计→代码一体化**：Peter Yang 今日新片把 Claude Design + Claude Code 串成六步流程，"规划占一半时间" 与官方 Plan Mode 叙事一致。
