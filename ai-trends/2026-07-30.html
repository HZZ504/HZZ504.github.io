AI 动态追踪日报 — Claude Cowork & Claude Code

一、高级用法精选（按难度分层）

Level 1 — 基础配置

  • 给 Claude Code 上"物理约束"：@arqdigital_io 分享西语版硬核配置：把 Claude Code 关进 sandbox + 配好 claude.md，"放开它的手"；同时禁用 sudo——先划安全边界，再给自主权。
  • 从 root 目录启动 + 立即 /init：John Kim（Meta Staff Engineer）50 条 tips 的前两条依然是新手最高性价比动作；CLAUDE.md 是分层生效的，保持精简、结构化为 What / Domain / Validation 三段（视频，46万次观看）。
  • 学会看服务状态页：@Nosunosukawa1 提醒：7/29 19:45–21:26 UTC 出现 "Elevated errors across all models" 故障，现已全线 Operational——遇到异常先查 status.anthropic.com，别急着改自己的配置。

Level 2 — Skills 技巧

  • 「Record a skill」实测：@KameAIHacks（❤️1 👁31）实测 7 月 21 日上线的 Claude "Record a skill"：不会写 prompt 也没关系——把流程做一遍录下来，Claude 自动沉淀成可复用 Skill，秘诀是"先给 1 组正确示范，再拿别的数据试一轮"。
  • 可直接照抄的 10 个 Skills：Skill Leap AI 新片 "10 Claude Skills You Should Copy Today"（1.1万次观看 · 2天前）给出内容引擎、数据可视化仪表盘、研究审计器等模板，统一品牌语气与输出质量。
  • 别买"信息商材"，直接问 Claude：@yugen_matuni（🔁5 ❤️35 👁1,907）犀利观点：市面上卖的所谓 Tips 合集，99% 的问题直接问 Claude Code/Cursor 就能解决——把钱花在订阅而不是二手教程上。

Level 3 — 定时任务

  • Claude Code Loops 上手 7 分钟：Developers Digest "Claude Code Loops in 7 Minutes"（4.2万次观看）：Loop 限定在当前会话、带最高 10% 调度偏移；示例包括每日 git recap 和 Hacker News 邮件自动化，并讲清何时该改用更持久的方案。
  • Cowork 定时任务已是教程标配：Tina Huang（38万次观看）与 AI Foundations（6.8万次观看）的 Cowork 教程都单列 "Scheduled Tasks" 章节——晨报、周报、项目内定时任务是最常见的三个落地场景。

Level 4 — Connectors & MCP

  • Cowork 插上你已付费的工具：Dr. Fernando De La Peña Llaca 的图文帖（👁33）演示小企业玩法：Cowork 桌面端 → Customize → Plugins 搜索 "Small Business" 安装 → 连上 QuickBooks / HubSpot / Canva / DocuSign / Google，一句 prompt 完成月度对账并生成给会计的摘要包。
  • MCP 选型看老片：Edmund Yong "800+ hours of Learning Claude Code in 8 minutes"（91万次观看）的 "My favorite MCP servers" 章节仍是被引用最多的 MCP 入门清单。
  • Turing × Anthropic 官方课程体系：@turingcom（💬1 ❤️3 👁73）宣布 Frontier Fellow 福利：3 个月 Claude Max 5x + Anthropic 主讲四部曲工作坊——Claude Code Foundations/Advanced + Claude Cowork Foundations/Advanced，官方培训首次把 Cowork 与 Code 并列成体系。

Level 5 — Hooks 自动化控制

  • PostToolUse 自动格式化 + 拦截危险命令：John Kim tips 47–50：Hooks 可拦截任意动作——PostToolUse 自动跑 prettier、PreToolUse 阻断危险命令，把"希望发生"变成"必然发生"。
  • 让 Claude 自己写 Hook：YouTube Shorts "Claude sets up a PostToolUse hook for itself"（584次观看）演示元操作：直接让 Claude 为自己配置 Hook，配置成本趋近于零。

Level 6 — 子代理编排

  • 像 tech lead 一样管 sub-agents：Sajjaad Khader "Learn 80% of Claude Code in 10 Minutes"（15万次观看）第 6 层：任务队列 + plan mode + ultra-thinking，工程师的角色正在变成 AI 团队管理者。
  • Subagents = 隔离上下文：John Kim Tip 39/40：sub-agent 的核心价值是独立 context window，避免主会话被污染；同时警惕"指令过载"——每个 agent 只给它该知道的。

Level 7 — 专家级工作流

  • 六步 AI 原生设计流程（今日新片）：Peter Yang "Full Tutorial: From Idea to App with Claude Design and Claude Code in 25 Minutes"（3,178次观看 · 11小时前）：定义用户问题 → design.md → Claude Design 原型 → 一份 HTML spec 打通产品/设计/技术 → 覆盖边缘 case → Claude Code 实现；核心论点：规划应占一半以上时间。
  • 精读 Anthropic 官方"围堵 Claude"长文：@yibie（👁123）强推 Anthropic 工程团队 7 月 29 日的长文（How we contain Claude）：4 个真实安全事故 + 3 种隔离模式（claude.ai / Claude Code / Cowork），核心教训一句话——不要信任 agent 的自我约束，要信任架构隔离。
  • 开源平替生态成型：@Justshareit518（👁23）介绍 OpenWork——开源版 Claude Cowork，基于 OpenCode，跨 macOS/Windows/Linux，可在 Cursor、Claude Code、Codex 间共享 workflows、MCPs 和 skills。
