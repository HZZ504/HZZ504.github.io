## 今日焦点

**Claude Cowork 正式登陆 Chrome 侧边栏。** Anthropic 于 8 月 12 日宣布，Claude in Chrome 的侧边栏会话现在就是一个完整的 Cowork 会话：对话保存到历史记录、Skills 和 Connectors 直接在浏览器内可用、浏览器里开始的任务可以在桌面端 / 网页端 / 移动端无缝继续。Max 和 Team 用户今日可用，Pro 用户未来几周陆续开放。这是今天 X 上 Claude 社区讨论度最高的话题。

## 一、高级用法精选（按难度分层）

### Level 1 — 基础配置

- **善用 `claude -c` 的目录作用域**：X 上日语社区热议的小技巧——`claude -c` 恢复会话时只查找"当前文件夹"的历史，会话并没有丢失，切回原目录即可恢复。养成"一个项目一个目录"的习惯，历史管理会清晰很多。
- **CLAUDE.md 是每次会话的起点**：把文件路径、格式规范、写作语气、行为红线写进 CLAUDE.md，比每次重复提示高效得多。

### Level 2 — Skills 技巧

- **Skills 做减法而非加法**：YouTube 博主 Nate Herk 昨日发布的视频《I Deleted All My Claude Skills... And Claude Got Smarter》引发讨论——过多、过时的 Skills 指令互相冲突反而降低输出质量。定期清理旧指令，只保留高频、明确的技能。
- **用 Claude Code 给其他 AI 工具写提示词/Skill**：日本博主 @tanabe_fragm 演示了用 Claude Code 为视频生成模型 MiniMax H3 编写结构化提示词，并封装成可复用 Skill——"用 Claude 管理其他 AI"正成为一种工作流模式。

### Level 3 — 定时任务

- Cowork 的 scheduled tasks 可将"每日采集 → 生成报告 → 构建发布"整条链路自动化（本日报即为实例）。配合 Chrome 侧边栏同步后，定时任务产出的会话现在也能在任意端继续追问。

### Level 4 — Connectors & MCP

- **Chrome 侧边栏继承全部 Connectors**：本次更新后，浏览器内的 Cowork 会话无需重新配置即可使用已有的 Skills 和 Connectors，内部仪表盘、遗留系统等没有原生连接器的网页可以直接由 Claude in Chrome 代操作。
- **Wix 官方 MCP Server** 等垂直平台连接器持续涌现，建站、设计类工作流可直接挂接。

### Level 5 — Hooks 自动化控制

- 社区安全提醒：Black Hat USA 上披露的 Claude Code CVE-2026-54316（已在 2.1.163 修复）表明，CI 中运行 agentic 工具时应固定版本、最小化 secrets 暴露。用 hooks 给敏感命令加白名单/审计日志是当前推荐做法。

### Level 6 — 子代理编排

- Meta 工程师 John Kim 的 50 条 tips（46 万播放）中反复强调：大任务先 plan mode 拆解，再由子代理并行执行、主代理只做验收，比单线程长对话稳定得多。

### Level 7 — 专家级工作流

- **Compound Engineering 五段式流水线**：X 用户 @ZainJutt1011 分享其 Claude Code 工作流——Q/A → plan → execute → review → deploy，全程由 Compound Engineering 插件驱动，人只在 plan 和 review 两个关口介入。
- **跨平台迁移趋势**：OpenAI 于 8 月 12 日推出"从其他 Agent 导入工作"功能，可导入 Claude Code / Cowork 的项目、聊天、skills 和插件——各家 agentic 工具的互操作与迁移战已经打响。

## 六、跨平台趋势总结

1. **"一个会话，处处运行"成为主线**：Chrome 侧边栏并入 Cowork 会话体系后，Claude 完成了桌面、网页、移动、浏览器四端的会话统一，X、YouTube 官方频道与科技媒体（9to5Mac、Engadget、The New Stack）同日集中报道。
2. **Skills 治理开始被认真对待**：从 Nate Herk 的"删 Skills 反而更聪明"到社区对指令膨胀的吐槽，风向从"堆技能"转向"精简与定期清理"。
3. **互操作战开打**：OpenAI 推出从 Claude Code/Cowork 导入项目、聊天、Skills 的迁移工具，agentic 生态从功能竞赛进入"降低切换成本"竞赛。
4. **安全与合规持续升温**：Black Hat 披露的 CI 漏洞（已修复）、Cowork VM 逃逸研究、欧盟 AI 法案水印落地，提醒重度用户关注版本更新与审计能力。

## 七、进阶路线图

1. **入门**：看 Jeff Su《Learn 80% of Claude Cowork in Under 20 Minutes》分清 Chat/Cowork/Code 定位 → 配好 CLAUDE.md。
2. **进阶**：跟 Metics Media 六层进阶路线练 Skills 与 Connectors → 学会用定时任务自动化一条完整链路。
3. **高阶**：实践 John Kim 50 条工程师技巧中的 plan mode + 子代理编排 → 引入 hooks 做质量门禁。
4. **专家**：搭建 Q/A→plan→execute→review→deploy 五段式流水线，人只守 plan 与 review 两关。
